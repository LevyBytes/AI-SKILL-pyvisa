## Installation

### Installation

PyVISA serves as a frontend for the VISA library and requires Python 3.10 or later in the checked upstream revision (843d62a50). Check the selected release before installing on older Python versions.

You can install it using [pip](http://www.pip-installer.org/):

```text
$ pip install -U pyvisa

```
